          Dados, backup e configurações

          Onde ficam suas vendas?

          As vendas ficam salvas só neste aparelho, neste navegador. Se você limpar os dados do navegador ou trocar de celular, elas somem. Faça backup com frequência (uma vez por semana, por exemplo) e guarde o arquivo no Google Drive ou mande para você mesmo no WhatsApp.

          Configurações

          Usado no custo de produção (horas × R$/hora). Padrão R$ 1,50/h, editável. Se deixar vazio e salvar, volta para 1,50.
          Preço sugerido = custo × (1 + markup%). Ex.: 100% dobra o custo. Sem valor padrão: vazio = não sugere preço.

          Exportar

          O JSON serve para restaurar no app. O CSV abre no Excel e no Google Planilhas.

          Restaurar backup

          Escolha um arquivo .json gerado por este app.

          Dados de exemplo

          Quer ver o app funcionando antes de usar de verdade? Carregue vendas fictícias (marcadas como exemplo) e remova quando quiser, sem afetar suas vendas reais.

          Cópias de dados corrompidos

          Há cópias antigas de dados que não puderam ser lidos.

          Zona de perigo

          Apaga todas as vendas deste aparelho. Não dá para desfazer (a não ser que você tenha um backup).
